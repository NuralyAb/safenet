# Источники данных (коллекторы)

Все источники — за единым интерфейсом `BaseCollector`, через реестр. Конвейер
один: `fetch → SSRF-проверка URL → EvidenceStore.store (SHA-256 + WORM) → контракт`.
Хрупкая логика на источник изолирована в адаптере.

## Матрица возможностей и легальности

| Источник | Метод | Легальность | Статус |
|----------|-------|-------------|--------|
| **YouTube** | yt-dlp (или офиц. Data API) | публичный контент; API имеет ToS-лимиты | ✅ адаптер готов |
| **Telegram** | MTProto (Telethon) | публичные каналы; нужен api_id/hash + сессия | 🟡 каркас, нужна обвязка креды/сессия |
| **TikTok** | yt-dlp (неофиц.) | ⚠️ **нарушает ToS**, хрупко, нужны прокси | 🟡 адаптер есть, с пометкой |
| **Instagram** | yt-dlp (неофиц.) | ⚠️ **нарушает ToS**; Graph API только для своих business-аккаунтов | 🟡 адаптер есть, с пометкой |
| **WhatsApp** | — | ❌ **невозможно**: E2E-шифрование, нет публичной ленты | ❌ зарегистрирован, падает с объяснением |

### Почему WhatsApp нельзя
WhatsApp — сквозно зашифрованный мессенджер **без публичного контента**. Технически
нечего собирать (сообщения видны только участникам), юридически — перехват чужой
переписки незаконен. Business API обрабатывает только переписку **вашей** организации,
а не сторонний мониторинг. Адаптер намеренно оставлен в реестре и **падает с понятной
ошибкой**, а не делает вид, что собирает.

## ⚠️ Прототип vs боевой продукт
- Скрейпинг TikTok/Instagram нарушает их ToS и ломается при редизайнах. Для боевого
  продукта правоохраны нужен мандат/официальные соглашения; для прототипа — только
  **синтетические/демо** цели (см. [CLAUDE.md](../CLAUDE.md)).
- Внешний AI (OpenAI) обрабатывает собранное → правило «только демо-данные» действует
  и здесь.

## Сетевые границы
Реальный сбор идёт только в `collector-worker` (есть egress). `processing-worker`
(обработка чужих медиа) — в `internal`-сети **без интернета**. URL каждого айтема
проходит SSRF-allowlist (`collector_allowed_hosts`) перед скачиванием.

## Добавить источник
1. Новый адаптер: подкласс `BaseCollector` (или `YtDlpCollector`) c `@register("name")`.
2. Реализовать `fetch(target) -> list[CollectedItem]` и `health()`.
3. Извлечь идентификаторы из текста через `extract_identifiers`.
4. Тест в `test_collectors.py` (с fake-сетью).
