# SafeNet KZ — метрики качества

Сгенерировано `python -m scripts.evaluate_safenet --write-docs`. Режим: только детерминированные правила (без LLM) — воспроизводимо и офлайн.

«Помечено» = балл ≥ 40 (уровень «средний» или «высокий») — материал уходит специалисту на ручную проверку. Система не выносит вердикт.

## Протокол оценки (честно)

Все выборки синтетические и размечены вручную. Чтобы не обманывать себя переобучением, каждую новую выборку прогоняли **один раз вслепую**, фиксировали результат и только потом (для test и holdout) разбирали ошибки:

| Прогон | Версия правил | Precision | Recall | FPR | Комментарий |
|---|---|---|---|---|---|
| test, вслепую | v1 | 100% | 65.3% | 0% | гейты слишком строгие, словарь переобучен на dev |
| holdout, вслепую | v2 | 90.2% | 76.7% | 8.3% | после разбора ошибок test |
| **blind, вслепую (независимый автор)** | **v3** | **96.6%** | **63.3%** | **3.3%** | **главная оценка обобщения**: выборку написал отдельный исполнитель, не видевший правил |

Вывод: правила дают **высокую точность и мало ложных срабатываний** (это приоритет ТЗ), но на незнакомом стиле пропускают около трети схем: суммы прописью в эфирах, только эмодзи, казахские чаты без ключевых слов. Для recall в архитектуре предусмотрен LLM-помощник с проверкой цитат (`safenet_llm_assist`). Замер «правила + LLM» на слепой выборке не выполнен: у подключённого ключа OpenAI исчерпана квота. Дальше — обучаемый классификатор поверх признаков (см. `docs/ROADMAP_SAFENET.md`).

Ниже — текущие цифры по каждой выборке. Для blind это версия v3 плюс одна правка формата OCR-баннеров («Қатысу: 1000 ₸»), найденная на собственных демо-скриншотах; затронут один пример blind. Поэтому официальной слепой цифрой остаётся строка таблицы выше.
