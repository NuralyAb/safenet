# SafeNet KZ — цифровой щит против незаконных схем в соцсетях и мессенджерах

Прототип для хакатона **SafeNet KZ** (Шымкент, 2026). Система автоматически находит **признаки**
трёх схем в соцсетях и мессенджерах Казахстана, оценивает уровень риска (низкий / средний / высокий)
и объясняет каждое срабатывание дословными цитатами:

| Трек | Что находит |
|---|---|
| 1. Розыгрыши под контролем | платное участие (взнос, номера, Kaspi), случайный выбор победителя, доход организатора, серии; отличает бесплатные конкурсы |
| 2. Скрытая игра | нативная реклама казино («как я поднял»), промокоды, трекинговые ссылки, сокращатели, зеркала, стримы, каналы-прокладки |
| 3. Стоп-пирамида | нереалистичная доходность (числовой анализ «вложи X → получи Y», % в день), доход от привлечения, давление, «выплаты», структура группы: организатор, кураторы, шаблонные сообщения |

> **Ключевой принцип.** Система не объявляет схему незаконной: она показывает признаки возможного
> нарушения. Законность проверяет специалист.

≈350–900 материалов/с на ядро. Протокол и история прогонов — в [docs/METRICS.md](docs/METRICS.md).

## Возможности

* **Проверка контента**: текст поста, транскрипт эфира, сообщение, **скриншот** (OCR Tesseract rus+kaz+eng
  работает on-prem, без внешних API), видео по ссылке или файлом (речь + кадры).
* **Анализ группы**: экспорт Telegram (`result.json`) или WhatsApp (`.txt`). Находит организатора и
  кураторов (как кандидатов), шаблонные «отзывы о выплатах», самые рискованные сообщения.
* **Мультиязычность и маскировка**: русский, казахский (с казахской раскладкой и без), транслит, сленг;
  `к@зино`, `К А З И Н О`, латиница-двойник, стилизованный Unicode, эмодзи.
* **Объяснимость**: каждый признак — с цитатой, источником (подпись / речь / скриншот / LLM) и способом
  маскировки. Гейты и смягчения видны строками, Σ вкладов = балл. LLM никогда не ставит балл, а его
  находки без дословной цитаты отбрасываются.
* **Очередь аналитика**: фильтры по треку и уровню, сортировка «риск × охват», решения «Передать
  специалисту / Наблюдать / Ложное срабатывание» с журналом аудита.
* **Граф связей**: аккаунты ↔ Kaspi-номера ↔ карты (маскированные) ↔ промокоды ↔ каналы ↔ домены,
  сообщества и центральные узлы (Neo4j GDS).
* **Поиск**: Хантер (автономные запросы по трём трекам на RU и KZ), Радар, мониторинг аккаунтов.

## Быстрый старт

```bash
cp .env.example .env              # секреты; OPENAI_API_KEY необязателен (только синтетика!)
docker compose up --build -d      # весь стек
docker compose exec backend alembic upgrade head
docker compose exec backend python -m scripts.seed_demo        # аналитик analyst-1 (печатает пароль)
# веб: http://localhost:5173  →  «Обзор» → «Загрузить демо» (синтетические сети и группы)
```

* Без внешнего AI: «Настройки» → AI-провайдер = `mock`. Правила, OCR (Tesseract) и граф работают офлайн.
  Если ключ OpenAI без квоты, срабатывает предохранитель: после первого `insufficient_quota` система
  10 минут работает только на правилах, без ожидания ретраев.
* Демо-скриншоты для загрузки: [docs/demo_screenshots/](docs/demo_screenshots/). Демо-группы выбираются
  кнопками на вкладке «Проверка контента → Группа / чат».

### Метрики и тесты

```bash
docker compose exec backend python -m scripts.evaluate_safenet --set all      # все выборки
docker compose exec backend python -m scripts.evaluate_safenet --set blind --errors
docker compose exec backend python -m scripts.generate_safenet_dataset        # пересобрать dev
docker compose exec backend python -m pytest -q -m "not integration"          # бэкенд
docker compose exec frontend npx vitest run                                   # фронтенд
```

## Устройство

```
backend/app/services/safenet/
  normalize.py   виды текста против обфускации, свёртка казахских букв, транслит, язык
  lexicon.py     признаки трёх треков (RU/KZ/translit/сленг), веса, исключения
  numeric.py     доходность «вложи→получи», % за период, номера карт (Луна), маскирование
  detector.py    признаки с цитатами по сегментам (подпись/речь/OCR/чат) + LLM с проверкой цитат
  scoring.py     детерминированный балл по трекам, гейты, смягчения, уровни
  group.py       разбор экспортов Telegram/WhatsApp, шаблоны, роли, риск группы
  evaluation.py  precision / recall / F1 / FPR, срезы, матрица ошибок, скорость
  demo.py        синтетические аккаунты-сети и группы для демо
  data/          dev / test / holdout / blind выборки, демо-чаты
frontend/src/features/safenet/   Проверка контента, анализ группы, Метрики и методика
```

Стек: FastAPI · Celery · PostgreSQL · Neo4j (GDS) · Qdrant · Redis · MinIO (WORM, цепочка хранения
доказательств) · Temporal · React + TypeScript + TanStack Query · Tesseract · ffmpeg · yt-dlp / Telethon.
AI-провайдер абстрагирован: `openai | anthropic | local | mock`. Подробнее — [ARCHITECTURE.md](ARCHITECTURE.md).

## Этика

Только синтетические и обезличенные данные; во внешние API — только синтетика. Номера карт маскируются,
роли в группах помечены как кандидаты, каждое решение принимает человек. Система не содержит функций,
помогающих организовывать схемы.
